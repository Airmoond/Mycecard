# 敌人标准模型

按行动强度、循环节奏、状态成长和生命评估敌人。基础单位为1 E：一个敌人行动造成12点伤害或获得10点格挡；行动直接价值为伤害/12＋新增格挡/10。1 E对应[卡牌模型](../卡牌标准模型/README.md)的2 U。

工具支持固定基础伤害、自身格挡、自身力量、对玩家施加虚弱和易伤。未支持的治疗、持续能力、格挡转伤害等效果会报错，不按零收益处理。

## 运行

在包含 project.godot 的项目根目录执行：

~~~powershell
python tools/project.py experiment --scenario models
~~~

该命令同时生成卡牌模型和敌人模型，输出位于 .godot/experiments/<run>/source 内的对应模型目录。实验清单记录输入、输出和来源；原工作树的归档JSON、报表和原SHA保持不变。直接在工作树运行重新评估脚本会被保护入口拒绝。

## 归档条件

历史设计参考为普通敌人首行动约0.7 E、完整行动最高1.8 E；Boss首行动约1.3 E、最高2.6 E。这些数值是设计参考，允许不同机制形成不同节奏。

归档数据包含4种普通敌人和3种Boss：

| 敌人 | 归档机制与生命 |
| --- | --- |
| 哥布林战士 | 30生命；8伤→12伤固定循环 |
| 遗迹守卫 | 99生命；13盾→8伤×2→18伤固定循环 |
| 铁壁哨卫 | 连续三个防守行动后重击；新敌人实验记录具体参数 |
| 咒缚侍徒 | 两步交替施加虚弱和易伤 |
| 狂怒蛮兵 | 每行动先增加2力量再攻击，力量本场持续且无上限 |
| 铁冠暴君 | 110生命；8伤＋6盾→7伤×3→12伤＋3盾→13盾 |
| 灾厄祭司 | 100生命；虚弱1后8伤＋6盾→易伤1后10基础伤→12基础伤＋6盾→13盾 |

狂怒蛮兵是持续成长例外，不能用1.8 E作为长期上限。普通敌人100生命的设计偏好和基础六牌组约80%的实验目标不适用于Boss。

## 时序与解释范围

敌人格挡在自身回合开始清理，新格挡保护下一玩家回合。虚弱倍率为0.75，易伤为1.5；攻击按效果顺序结算，各段在倍率后取整。首次施加减益跳过当轮递减，追加已有减益不重新建立跳过标记。

直接E已经包含力量和易伤的伤害增量。参考压力另计虚弱的防御潜力：均衡玩家每轮打两张6伤基础攻击，虚弱后各4伤，少造成的4伤对应0.4 E；这部分不再作为额外生命加入存活模拟。

固定预算的三种参考打法假定每轮拿到所需基础牌，用于解释节奏，不表示真实洗牌胜率。玩家先手也可能在敌人行动前击杀目标，循环总供给不能等同实际失血。

本目录的归档结果不能直接代表现版本平衡。完整抽牌和牌组模拟见[综合模型](../综合数值模型/README.md)；基础牌组校准见[普通敌人实验](../综合数值模型/新敌人实验/README.md)，不同构筑与入场生命对照见[Boss实验](../综合数值模型/Boss实验/README.md)。

人工试玩可在Godot打开[敌人试炼](../综合数值模型/新敌人实验/敌人试炼.tscn)或[Boss试炼](../综合数值模型/Boss实验/Boss试炼.tscn)，按F6运行。历史来源及复算边界见[数值基线](../docs/current/numerical-baselines.md)。

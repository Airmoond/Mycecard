# 综合数值模型

版本v0.1，2026-10-03。以独立卡牌、敌人标准模型为尺度，结合真实战斗结算，评估牌组、生命、抽牌、行动顺序及连续遭遇。模型用于比较配置与发现问题；数值调整需要结合实际试玩。本文记录旧地图实验条件，运行入口与历史边界见[README](./README.md)。

## 1. 三层结构

| 层次 | 量化对象 | 计算方式 |
| --- | --- | --- |
| 单卡／单行动 | 伤害、格挡、费用、抽牌、状态、武器等 | 卡牌1 U=6伤／5格挡；敌人1 E=12伤／10格挡，1 E=2 U |
| 单场战斗 | 实际牌组与双方生命共同形成的压力 | 使用独立BattleSession、BattleState、行为队列和伤害规则，按手牌与意图出牌 |
| 连续遭遇 | 获牌、普通战失血、休整、Boss入场生命 | 跨场保存当前与最大生命、获得的卡牌；每场重新初始化力量、能力、武器与牌堆 |

U/E衡量行动供给；血量决定这些行动有多少机会兑现。敌人行动均值乘血量可粗略排序，但不能代替按顺序结算：格挡浪费、先手击杀、能力成长、多段力量与回血都会改变结果。

## 2. 输入与设计目标

正式资源提供卡牌费用、效果和词条，角色起始生命与基础牌组，候选池和稀有度，敌人生命与行动循环，遭遇能量／抽牌／手牌上限，以及休整恢复量。当前角色基础50血，3能量、5抽牌、10手牌上限。

敌人设计参考区间为：普通敌人首行动约0.7 E、允许上限1.8 E；Boss首行动1.3 E、允许上限2.6 E。成长可选，上限不要求达到。当前普通8伤的0.667 E按一位小数约为0.7；对约数目标允许0.05 E的整数取值误差。

模拟参数独立保存：固定种子、样本量、参考构筑、双方生命扫描、策略与评分权重。生命扫描只改复制资源；正式玩家仍50血，遗迹守卫为99血。

## 3. 战斗中的生命账目

无状态的单次行动供给仍按D/12＋B/10；实际压力由每轮执行后的状态决定：

- 攻击先按力量、虚弱、易伤及多段取整计算，再抵消真实格挡，剩余部分扣目标生命，超杀不重复计收益。
- 普通卡、能力与武器按正式效果顺序结算；回血按实际效果恢复并受当前上限限制，减少最大生命可能同时压低当前生命。
- 玩家先行动，击杀后敌人不执行；敌人格挡保护下一玩家回合，到敌人自己回合开始时清理旧盾。
- 当前牌组决定抽牌密度，3能量限制可用组合；武器攻击不花能量但每回合只有一次，损坏、强化与回手照正式规则处理。

记录初始当前／最大生命H0、M0，以及结束值H1、M1：

**净失血L = H0−H1；上限损失C = M0−M1；余血比例R = H1/M0。**

净失血可为负，例如受伤入场后回血超过本场损失。上限损失独立列出，不能与即时扣血重复相加；R使用原上限，避免血祭减少上限后人为提高分数。

同时核对每次操作观察到的生命扣减与恢复：累计扣减−累计恢复=L。这是操作前后的生命账目，不宣称记录了效果内部全部过量治疗或伤害供给；致死时扣血被0截断，因此另列失败时敌人余血，不把失败的50失血误读为“只需50血就能过关”。

## 4. 输出与综合分

| 指标 | 用途 |
| --- | --- |
| 首行动／循环均值／峰值E | 区分起手、持续压力与爆发，核对设计上限 |
| 样本胜率与胜利数 | 在同一策略下比较配置的可通过程度 |
| 平均剩余血／净失血／上限损失 | 比较代价与后续战斗容错，平均包括失败样本 |
| 回合数／敌人余血 | 区分拖长战斗、提前击杀与接近成功的失败 |
| 卡牌实际打出样本率 | 判断是否因条件或策略未能兑现 |
| Boss入场血／实际休整回血 | 核对整局生命预算及休整溢出 |

暂定综合分：**Q = 70×样本胜率＋30×平均余血比例。** 两个权重在参数文件中公开，可调整。满血获胜为100分，全部死亡为0分；对相同牌组、血量与策略的改动可计算ΔQ。Q用于比较，不能让同分配置被误认为同样好玩，也不以单一Q替代各原始指标。

**单卡战斗增量 = 基础6张＋该卡的指标−基础6张的指标。** 同组使用相同种子列表，但增加一张牌会改变洗牌和后续随机调用，不保证两次抽牌一一相同。有限样本增量包含牌堆稀释、时序、条件与策略效果。

固定基础预算另计算理论最低生命需求：每轮假定执行同一伤害／格挡组合，持续到击杀；无治疗时最低H=累计实际失血＋1。它不模拟抽牌，也不代替真实策略。

## 5. 场景设计

独立单场实验覆盖全部29张单卡的两种原有敌人场景；基础6张、武器配合参考9张、随机合法开局9张；两种牌组各自扫描玩家35／50／65／80血与遗迹守卫40／75／99／120血。连续路线保留一场哥布林与遗迹守卫的历史拓扑参照，并另评估冻结实验地图的两场随机普通战与随机Boss。

随机开局复用正式三轮候选抽取，每轮选择第一张；奖励复用正式非传说抽取并选择第一张。这是中立、可重复的选择规则，没有自动优化构筑。参考构筑使用永恒（传说）、战神祝福（史诗）、上勾拳（稀有）。单卡7张牌组仅用于诊断。

历史连续路线由RunState使用tests/fixtures/phase5_run.tres初始化五层分支地图：开始→三条固定支线（普通、普通、休整）→共同Boss。开局从四种普通敌人池为每条支线抽两种不同敌人，跨路线可重复；从三种Boss池抽一个最终Boss，并保存整局绑定，不在进入节点或返回地图时重抽。评估用独立地图种子（开局种子＋400000），按样本序号在a／b／c中轮换，因此24局各走8次支线；路线选择不优化。

正常完成三轮选牌和开始节点后，RunState进入选定路线；每场战斗使用节点绑定的实际遭遇资源。普通胜利后按正式候选规则抽奖励、取第一张并加入RunState.owned_cards，再完成该节点。九牌开局经两场胜利后为十一牌，跨场保存当前及最大生命；失败立即结束，不发奖励或推进后续。只经过所选支线的一次休整，按节点恢复15血且不超过本局实际上限，不能把另外两条支线的回血相加。击败实际绑定的最终Boss后完成节点并结算胜利；该主实验禁用藏品，藏品效果由独立配对实验比较。

## 6. 可重复性与局限

每个条件使用24个固定种子；实际结算来自BattleSession，不实例化战斗界面。来源SHA-256覆盖规则脚本、资源和评估GDScript；汇总时检查原始参数及两个独立标准模型，来源变化即拒绝使用旧样本。

策略是公开的意图贪心：看当前手牌、能量、双方状态、意图，优先致死，再选短期价值最高的行动。它不预知抽牌、不搜索完整回合最优顺序、不主动换装、不聪明选奖励；低血会提高防守权重。新效果类型会报错，未来必须扩展策略评分，但实际结算仍沿用游戏规则。

样本胜率的95% Wilson区间用于提示抽样规模；它只描述这些随机条件与此策略，不包含人类策略差异或模型偏差。24/24也不是玩家必胜。人工试玩需另记录牌组、Boss入场血、关键死亡回合，再据此调整配置或评估策略。

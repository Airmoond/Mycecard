# Boss独立实验

比较铁冠暴君、灾厄祭司与遗迹守卫的生命、构筑和伤后入场风险。自动评估使用 BattleSession 和“意图贪心v1”策略，不加载战斗界面；独立试炼提供人工试玩。

## 运行与输入输出

在包含 project.godot 的项目根目录执行：

~~~powershell
python tools/project.py experiment --scenario boss-validation
~~~

命令更新卡牌模型、敌人模型，依次运行生命对照和定稿独立验证，再生成本目录汇总。输出位于 .godot/experiments/<run>/source/综合数值模型/Boss实验，工作树的历史数据和原SHA保持不变。

| 文件 | 内容 |
| --- | --- |
| [评估参数.json](./评估参数.json) | 敌人、构筑、生命候选、样本与种子 |
| [评估Boss.gd](./评估Boss.gd) | 继承综合评估器；生命对照只改复制资源，验证只读正式资源 |
| [生命对照数据.json](./生命对照数据.json) | 不同生命条件的原始结果 |
| [验证数据.json](./验证数据.json) | 逐样本胜负、生命账目、实际打出卡牌及示例轨迹 |
| [生成Boss评估.py](./生成Boss评估.py) | 检查来源、生命、牌组稀有度和样本账目 |
| [Boss评估数据.json](./Boss评估数据.json)、[两种Boss设计.md](./两种Boss设计.md) | 归档汇总与解释 |

旧评估脚本无 validate 参数时执行生命对照，有参数时验证定稿资源；统一工具已处理这两步，不需要在工作树直接调用脚本。战斗观察上限为60回合，窗口耗尽或执行停滞记为错误。

## 归档设计

| Boss | 生命 | 固定行动循环 | 首行动直接E | 峰值直接E |
| --- | ---: | --- | ---: | ---: |
| 遗迹守卫 | 99 | 13盾→8伤×2→18伤（三步循环） | 1.300 | 1.500 |
| 铁冠暴君 | 110 | 8伤＋6盾→7伤×3→12伤＋3盾→13盾 | 1.267 | 1.750 |
| 灾厄祭司 | 100 | 虚弱1后8伤＋6盾→易伤1后10基础伤→12基础伤＋6盾→13盾 | 1.267 | 2.100 |

这些数值对应2026-10-03归档。三者均无力量成长；Boss行动参考上限为2.6 E，普通敌人的100生命偏好和基础六牌约80%目标不适用。

灾厄祭司实际攻击为8→15→18→0。首次施加减益跳过当轮递减，虚弱覆盖第二玩家回合，易伤覆盖第二、第三敌人攻击。首行动虚弱另有0.4 E的均衡参考防御潜力，不重复计入易伤增伤。敌人格挡在自身回合开始清理，新盾保护下一玩家回合。

## 归档样本与结果

生命对照从51000000种子开始，每个生命与构筑条件64场；新Boss候选生命为90/100/110/120/130，遗迹守卫保持99生命，共2,112场。

独立验证从62000000开始，每条件256场；35/50生命随机开局从62010000开始。三种Boss×四个条件共3,072场，训练种子不用于独立验证。

| Boss | 满血基础6张 | 满血参考9张 | 满血随机9张 | 35/50随机9张 |
| --- | ---: | ---: | ---: | ---: |
| 遗迹守卫 | 135/256（52.7%） | 256/256（100.0%） | 234/256（91.4%） | 194/256（75.8%） |
| 铁冠暴君 | 3/256（1.2%） | 256/256（100.0%） | 204/256（79.7%） | 126/256（49.2%） |
| 灾厄祭司 | 6/256（2.3%） | 256/256（100.0%） | 208/256（81.2%） | 155/256（60.5%） |

基础牌组为3打击＋3防御；参考构筑增加永恒、战神祝福、上勾拳；随机合法九牌每种稀有度取第一候选，不搜索最优构筑。同类条件共用种子，但不同牌组会改变洗牌，不能保证逐张抽牌一致。

以上胜率只描述归档策略与条件，不代表现版本或人类玩家胜率。基础牌组与参考构筑的差异说明Boss对构筑敏感；伤后入场还会降低通过率。单场实验没有奖励、休整、藏品和完整路线结算，不能替代整局平衡评估。

## 人工试玩

在Godot打开[Boss试炼.tscn](./Boss试炼.tscn)，按F6运行，选择三种构筑、50/50或35/50入场生命，再选择Boss。胜负后可返回；新战斗重新建立牌堆、力量、状态和武器，不继承跨场奖励或藏品。

试炼复用正式界面、规则和卡牌实例，部分立绘仍是占位素材。相关机制与重置检查见[Boss机制测试](../../tests/new_boss_mechanics_test.gd)、[试炼测试](../../tests/new_boss_trial_test.gd)。

完整区间和来源见设计报告；历史边界见[数值基线](../../docs/current/numerical-baselines.md)。[普通敌人3,000场验证](../新敌人实验/README.md)与本目录分开统计。

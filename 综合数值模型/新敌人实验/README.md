# 普通敌人校准与验证

本目录包含铁壁哨卫、咒缚侍徒、狂怒蛮兵的参数搜索、独立验证和人工试炼。训练、验证和正式敌人配置分别保存，训练脚本只修改复制的资源，不自动改写游戏数值。

## 运行

在包含 project.godot 的项目根目录执行独立验证：

~~~powershell
python tools/project.py experiment --scenario enemy-validation
~~~

命令更新卡牌模型、运行三种敌人的验证，再生成敌人模型和本目录报告。重新搜索参数使用另一条命令：

~~~powershell
python tools/project.py experiment --scenario enemy-calibration
~~~

两条命令分别创建 .godot/experiments/<run>/source 副本，输出写在副本内。校准结果需审查后手动应用到正式资源，再重新执行独立验证；不能把参与选参的样本当作独立验证样本。

## 实验条件

归档条件为50/50生命、3打击＋3防御、每回合3能量、5抽牌、10张手牌上限，玩家先手。使用“意图贪心v1”冻结策略，不查看未来抽牌，不含三轮开局选牌、武器、藏品、奖励或休整。

粗搜每条件128个种子；精调每条件512个，种子从31000000开始。独立验证从42000000开始，每敌人1,000个不重叠种子，共3,000场。搜索范围围绕已选方案的生命、基础攻击和格挡数字，不是所有行动或状态组合的穷举。

设计目标约80%，75%～85%用于比较样本，不是硬性阈值或人类玩家胜率保证。95% Wilson区间只描述抽样不确定性，不包含策略差异。

## 机制与解释范围

- 三种敌人的归档定稿生命均不超过100；早期169/235生命方案保留作历史对照。生命、格挡节奏、伤害和状态频率共同影响压力，生命不直接折算成行动E。
- 普通行动参考上限为1.8 E。狂怒蛮兵持续每行动增加2力量，是无长期上限的成长例外；力量仅持续本场，12行动峰值只是观察窗口。
- 铁壁哨卫归档首行动为2伤＋7盾，约0.867 E，高于0.7±0.05 E的通用起手目标；完整行动峰值仍不超过1.8 E。
- 咒缚侍徒无外部状态时攻击为9→16→13→16，之后重复13→16；易伤行动本次即获得倍率，倍率后逐段取整。玩家基础打击按6→4→6→4交替，两种减益各自消退，并非永久覆盖。
- 力量、易伤增伤已包含在实际攻击中，不重复估值。

本目录保留的JSON、报表和原SHA对应历史条件，不能直接代表现版本结果。副本验证使用现有代码及历史已选参数；修改资源后需保留新的输入指纹并重新验证，不改写旧记录。详见[数值基线](../../docs/current/numerical-baselines.md)。

[主综合报告](../综合量化评估.md)的单场基线和单卡加入实验仍只针对哥布林战士、遗迹守卫；本目录的3,000场验证单独统计。[敌人模型](../../敌人标准模型/README.md)的固定预算打法也不等同真实洗牌胜率。

# 三件藏品的真实路线对照

日期：2026-10-04，模型v0.1。Godot 4.6.1-stable (official)正式结算，768条路线、2175场战斗；3种牌组×无藏品及3件藏品×每组64个配对种子。

正式流程为三轮选牌后进入地图，点击开始节点，再从三件藏品中领取一件；领取后开放三条支线。无藏品仅作为隔离效果的实验对照，不是正式开始节点的第四个选项。

## 1. 当前效果与比较条件

| 藏品 | 正式资源中的效果 |
| --- | --- |
| 赤铜獠牙 | 每场战斗开始时，获得1点力量，持续本场战斗。 |
| 守誓盾徽 | 每场战斗的前3个玩家回合开始时，各获得3点格挡。 |
| 余烬圣杯 | 每次普通战斗胜利后，恢复6点生命。 |

初始生命50/50。每条支线两种不同普通敌人→一次休整→随机最终Boss；四组使用同一整张地图的全部7个战斗绑定，同一支线、起始牌组、战斗与奖励种子。种子从73000000开始，路线按a、b、c轮换，不针对藏品换线。每场普通胜利领取第一候选奖励，正式九牌满程为11张，六牌诊断满程为8张。

随机合法九牌按传说→史诗→稀有三轮抽候选，每轮固定选第一张；参考九牌为基础六牌＋永恒、战神祝福、上勾拳。六牌诊断先合法完成构筑，再在实验中替换回基础六牌，不是正式主流程可获得的开局。每个配对种子在三类牌组中也使用同一地图。

所走支线的128次普通敌人选择：铁壁哨卫31次、哥布林战士39次、咒缚侍徒29次、狂怒蛮兵29次。64个最终Boss选择：灾厄祭司27局、铁冠暴君21局、遗迹守卫16局。这些敌人分布在四组和三种牌组中保持一致；不同藏品可能导致中途死亡，实际打到的敌人数量会不同。

## 5. 已核对与观察限制

逐场核对生命扣除减战内治疗等于净失血，逐路线核对初始生命减战内扣血、加战内治疗、藏品治疗和唯一休整等于终局生命；同时核对最大生命、奖励次数、两种不同普通敌人、地图绑定不变、失败不继续及正式RunState的完整进度。首回合力量与前三回合格挡由正式BattleController生效，跨场重新创建战斗状态。

本实验统计胜负、生命、回合、实际治疗和死亡位置；没有直接追踪獠牙相对无力量的逐段增伤，也没有统计盾徽的格挡抵伤、溢出、保留或盾牌猛击增益，不能把模型估值写成这些指标的实测数据。关键时序、重复触发和卡牌配合另由机制测试验证。

自动策略继承综合模型，查看当前手牌、能量、双方状态和可见意图，不预知抽牌、不搜索最优出牌顺序、不主动换装、不优化选牌和奖励。每组64种子的结果用于首版试玩对照，不保证人类胜率，也不把原普通敌人基础牌约80%目标套用到藏品或整局路线。

# 卡牌标准模型

用统一单位比较卡牌的固定收益、条件收益与资源代价。基础锚点为1费造成6点伤害、1费获得5点格挡，基础牌价值记为1 U。

模型适合筛查数值差异和解释构筑条件；不模拟完整出牌过程，不能把逐卡评分相加作为整套牌组的伤害。抽牌、治疗、生命及最大生命代价的价格属于模型假设，需要结合实际战斗与试玩调整。

## 文件

| 文件 | 用途 |
| --- | --- |
| [标准模型.md](./标准模型.md) | 单位、估值公式、场景假设与回本条件 |
| [模型参数.json](./模型参数.json) | 效果系数、场景输入和模型版本 |
| [重新评估.py](./重新评估.py) | 读取卡牌资源，计算各场景收益并生成报表 |
| [评估数据.json](./评估数据.json) | 归档配置、分项计算与来源SHA-256 |
| [全卡牌量化评估.md](./全卡牌量化评估.md) | 29张卡牌的归档总表和逐卡说明 |

工具读取 cards/data 下的资源和本目录参数，输出本目录中的评估数据与量化报告。新增效果未定价、缺少逐卡说明或资源格式不匹配时会停止。

## 运行

在包含 project.godot 的项目根目录执行：

~~~powershell
python tools/project.py experiment --scenario models
~~~

该命令同时运行卡牌模型和[敌人模型](../敌人标准模型/README.md)。环境要求见[开发环境](../docs/current/environment.md)；Godot可通过 GODOT_BIN 环境变量或工具的 --godot 参数指定。

实验在 .godot/experiments/<run>/source 中执行，结果和来源清单位于对应实验目录，原工作树的归档结果不会被覆盖。不要直接在工作树运行重新评估脚本。

## 历史数据与解释范围

本目录参数和报表保留2026-10-03建立的实验条件及原来源SHA。报告中的“当前”指报告生成时点，不能直接作为现版本的卡牌强度结论；复算使用现有代码，也不等于恢复缺失的历史源码。

标准、短战和长战场景用于观察收益随战斗长度的变化。各卡的标准局面是机制样例，40生命参考敌人是模型输入，不表示正式敌人的配置。稀有度、获取方式和收益兑现条件需要另行考虑，基础牌价值为1不要求所有1费卡评分相同。

评估双方生命、实际抽牌和连续遭遇时，使用[综合数值模型](../综合数值模型/README.md)。归档保护和复算边界见[数值基线](../docs/current/numerical-baselines.md)。
